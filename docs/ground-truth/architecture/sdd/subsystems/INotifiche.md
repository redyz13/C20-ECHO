# Sottosistema Gestione Notifiche

Source: `C20_E.C.H.O._SDD.pdf`, v1.0.0 (2026-11-25), §3.10, pp. 25.
Provided interface: `INotifiche`.

## Provided services

| Service | Description |
|---|---|
| Invio delle notifiche | Delivers events generated by other subsystems to their recipients: proposals to Helpers, request outcomes to Callers, escalation requests and alerts to Supervisors. |
| Ritiro delle notifiche | Withdraws notifications that are no longer valid, such as a proposal that has been canceled or already assigned to another Helper. |

## Required services and dependencies

No required-service or dependency table is specified in §3.10.
