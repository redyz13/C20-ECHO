# Glossary

Source: SDD v1.0.0, § 4, pp. 25–26.

| Term | Definition |
|---|---|
| Spring Framework | Java enterprise application development framework adopted to implement server-side application logic and orchestrate system services. |
| JDBC / JPA | Java Database Connectivity / Java Persistence API; standard Java ecosystem technologies used by the Application Server to connect to the relational database and manage object persistence. |
| PostgreSQL | Open-source relational database management system (RDBMS) used to ensure transactional persistence and referential integrity of system data. |
| React Native | React-based framework for developing cross-platform user interfaces through reusable components, with React Native Web support for browser access. |
| TypeScript | Programming language extending JavaScript with static typing, used with React Native to reduce development errors and improve frontend maintainability. |
| WebRTC | Web Real-Time Communication; technology enabling real-time exchange of text messages and audio streams between users' devices, directly or through relay services when necessary, reducing application server involvement. |
