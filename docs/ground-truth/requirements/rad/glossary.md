# Glossary

Source: RAD v1.0.0, § 4, pp. 86–87.

| Term | Definition |
|---|---|
| Safe Access Path | Alternative access path allowing minors experiencing difficulties with parents or guardians to access the platform as guests without parental authorization. |
| Safe Escalation | Quick command and procedure allowing Helpers to request immediate Supervisor intervention in risky situations, imminent danger or circumstances beyond their competence. |
| Fallback | Procedure activated when no Supervisor is available during escalation. The Helper contacts emergency services or directs the Caller to qualified services, followed by mandatory reporting. |
| Deterministic Matching | Algorithm assigning each listening request to a group of available and eligible Helpers based on selected categories, Caller age, qualifications and previous feedback. |
| SPID/CIE | Simulated digital identity services used for registration, authentication, age verification and parental authorization verification. |
| Audit Log | Automatic and secure record of sensitive operations, including timestamps, actors and outcomes, without retaining communication content. |
| WebRTC | Communication technology used for real-time audio interactions between Caller and Helper. |
