# SC_GU_01 — Helper Qualification Verification

Source: RAD v1.0.0, § 3.4.1.5, pp. 38–39.
Actors: Supervisor, Helper.

| Step | Actor | System |
|---|---|---|
| 1 | The Supervisor opens "Helper Management". | Retrieves and displays the list of registered Helpers. |
| 2 | Selects a Helper profile and requests verification of the "Minor Management" qualification with the associated training organization. | Retrieves and displays the Helper's data. Queries the organization's simulated interface. Upon a positive result, confirms the qualification's validity in the Helper profile and displays confirmation. |
| 3 | Reviews the positive result and returns to the dashboard. | Closes the profile details and displays the list of registered Helpers. |
