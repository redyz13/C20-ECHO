# SC_GAI_02 — Listening Request Creation and Submission

Source: RAD v1.0.0, § 3.4.1.2, pp. 31–32.
Actors: Caller Minorenne, Helper A, Helper B, Helper C.

| Step | Actor | System |
|---|---|---|
| 1 | A 16-year-old Caller, authenticated through SPID/CIE with parental authorization, selects "Request listening". | Verifies that the Caller has no other active requests. Displays thematic categories and an optional description field. |
| 2 | Selects "Anxiety" and "Loneliness" and enters "I need someone to talk to". | Records the selected categories and description. |
| 3 | Submits the request. | Creates the request, associates it with the minor age group and selected categories, and matches available, compatible Helpers qualified to support minors. |
| 4 | Waits on the request screen. | Sends the proposal to Helpers A, B and C. Displays a waiting indicator and cancellation option. |
| 5 | Helper A receives the categories and description and accepts before the deadline. | Assigns the request to Helper A as the first to accept. Generates session nicknames "Betulla" (Helper) and "Papavero" (Caller), withdraws the other proposals and notifies the Caller. |
| 6 | The Caller starts communicating with Helper A. | Establishes pseudonymous text and audio communication. Shows the Caller only the Helper's nickname. Informs the Helper that the Caller is a minor and displays the Caller's nickname. |
