# Communication Management (RF_GC)

Source: RAD v1.0.0, § 3.2.4, p. 18.

| ID | Name | Description | Actors | Priority |
|---|---|---|---|---|
| RF_GC_1 | Text Chat | The system shall allow the Caller and Helper to exchange text messages in real time during a session. | Caller, Helper | High |
| RF_GC_2 | Audio Call | The system shall allow the Caller and Helper to make an audio call during a session. | Caller, Helper | High |
| RF_GC_3 | Feedback | At the end of each session, except those initiated through the Safe Access Path, the Caller shall provide mandatory anonymous feedback, using a rating scale to assess the perceived affinity and rapport during the listening session. The system shall also allow reporting of technical issues or intentional, unagreed interruptions by the Helper before support is completed. | Caller | High |
| RF_GC_4 | Session Termination | The system shall allow the Caller and the assigned Helper to terminate an active session. | Caller, Helper | High |
| RF_GC_5 | Helper Disconnection Alert | The system shall automatically notify Supervisors when a Helper accumulates a predefined number of reports of intentional, unagreed disconnections. | Supervisor | High |
