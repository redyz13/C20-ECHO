# User Management (RF_GU)

Source: RAD v1.0.0, § 3.2.2, p. 16.

| ID | Name | Description | Actors | Priority |
|---|---|---|---|---|
| RF_GU_1 | Helper Qualification Specification | The system shall allow assignment or verification of specific Helper qualifications based on the training completed. | Supervisor | High |
| RF_GU_2 | Supervisor Qualification Verification | The system shall grant Supervisor access only to users whose qualification has been verified with the relevant partner organization. | Supervisor | High |
| RF_GU_3 | Availability | The system shall allow Helpers to set or update their availability schedules. | Helper | High |
| RF_GU_4 | Personal Area Information Viewing | The system shall allow users to view information in their personal area. | Utente | High |
| RF_GU_5 | Personal Area Information Editing | The system shall allow users to modify personal area information not obtained through SPID/CIE. | Utente | High |
